Tecnologias Utilizadas

O projeto foi construído utilizando apenas tecnologias nativas da web, sem o uso de frameworks ou bibliotecas externas:

- **HTML5:** Estruturação semântica para melhor acessibilidade e SEO.
- **CSS3:** Estilização moderna utilizando Flexbox, CSS Grid, variáveis CSS e Media Queries para responsividade.
---

## ✨ Destaques do Projeto

- 📱 **Layout 100% Responsivo:** Adaptado para celulares, tablets e desktops.
- 🎨 **Design Autoral & Moderno:** Foco em usabilidade, hierarquia visual e navegação fluida.
- 💼 **Showcase de Projetos:** Exibição dos meus principais trabalhos com links para código-fonte
- ⚡ **Alta Performance:** Carregamento rápido por utilizar código nativo e leve.
