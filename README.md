Tecnologias Utilizadas

O projeto foi construído utilizando apenas tecnologias nativas da web, sem o uso de frameworks ou bibliotecas externas:

- **HTML5:** Semântica Forte: Excelente uso das tags nativas do HTML5 para melhor acessibilidade e SEO - 
Navegação por Âncoras - Arquitetura Modular: Estruturação clara baseada em contêineres 

- **CSS3:** Configurações Globais e Importações - Barra de Navegação 
Cabeçalho / Hero Section - Estilização de Seções Gerais - Seção "Sobre Mim
Cards e Serviços - Seção de Projetos -Seção de Contato e Links - Rodapé
